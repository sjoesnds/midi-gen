# MIDI Forge 0.31 — Genre DNA 2.0

Genre selection now influences a wider musical fingerprint. The candidate
judge uses per-genre targets for density/space/register plus rhythmic identity,
melodic leaps, motif recurrence, surprise and repetition. The profiles are
soft targets rather than hard rules, so the 1000-candidate search can still
produce variation inside a genre instead of cloning one preset.

Genres covered: Universal, Trap, House, Techno, Boom Bap, Ambient, Cinematic,
R&B, Pop, Drill, DnB, Jersey, Afro, Hyperpop, Experimental and Lo-Fi.
