# MIDI Forge 0.29 — Musical Mutations

- MUTATE now operates across unlocked chord, bass, melody and arp layers.
- Melody/arp pitch mutations are snapped to the active scale.
- Chord mutations favor voicing changes rather than destroying harmonic identity.
- Rhythm mutation stays on the 1/8-note structural grid (2 x 1/16 steps).
- Note length and velocity receive controlled variation.
- LOCK CHORDS/BASS/MELODY/ARP are respected during mutation.
- EVOLVE continues to use a gentler mutation amount.
