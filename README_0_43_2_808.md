# MIDI Forge 0.43.2 - a real 808

Problem: Sound = 808 ran the melody generator in a low register (several long, wandering, overlapping notes plus the
chord / arp layers = it read like chords).  An 808 is ONE voice.

- Sound = 808 now generates only the 808 line: no chord, bass or arp layers in the loop.
- New `add808()` generator: kick-locked rhythm cells per genre (Trap / Drill, House / Techno, Jersey / Afro, RnB / Lofi ...),
  beat 1 = chord root of the progression, other hits mostly root, sometimes fifth or octave hop, phrase ends may step into the
  next root. Rhythm cell repeats (A A' B A''). Melody Density / energy choose sparse or busy cells.
- Strictly monophonic: never two notes at once, notes end before the next hit (small breath), range E1..D3 whatever the Octave control says.
- Root placement follows the previous note (small moves between roots).
- Candidate mutations do not scramble the 808 line.
- Articulation defaults to Off (a slide overlaps notes; on a polyphonic patch that sounds like a chord).
  Turn Slides on only when the 808 patch is mono / legato with portamento.
- Quality checks for 808 added to tests/qa_main.cpp.
