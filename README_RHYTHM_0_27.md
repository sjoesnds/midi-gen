# MIDI Forge 0.27 — Rhythm Engine 2.0

## Changes
- Expanded melody rhythm vocabulary from 16 to 24 phrase-level patterns.
- Added straight, sparse, syncopated, driving and broken rhythm families.
- Groove DNA now affects accents and sustain rather than introducing random timing drift.
- Off-grid 16th positions remain limited to deliberately syncopated patterns.
- Existing Phrase Memory, Humanization, Harmony Intelligence, Magic DNA and Taste Learning remain intact.
- 1000-candidate search and diversity selection remain unchanged.
