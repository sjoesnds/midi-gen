# MIDI Forge 0.8.0

MIDI Forge — JUCE VST3 MIDI generator.

0.8.0 upgrades the melody engine to phrase-first, context-aware generation with motif reuse, chord-tone gravity, controlled interval distributions, contemporary rhythm priors, phrase cadences, and humanized dynamics. Existing Piano Roll, Undo/Redo, Hook, SoundCloud, MIDI export and drag-to-DAW functionality are retained.
