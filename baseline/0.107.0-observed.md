## 0.108.0 ablation protocol

The report compares baseline with 19 named score functions, nine explicit Composer Judge aggregate groups and Taste ML disabled. Each condition uses the same numbered fixed seed set (default 108000–108255). Each run gets a fresh settings folder and the same deterministic synthetic Taste context (one like and one dislike from that seed's initial bank), so personal `taste.json` state cannot contaminate results.

The CSV records event counts, tonal-safety fraction, overall and melody-only grid fractions, unique melodic fingerprints across the eight variations, simple/balanced/complex loop counts, mean attacks per bar, mean distinct pitches, mean pitch range, runtime and a whole-bank fingerprint.

CI runs a two-seed pilot and uploads it as an artifact. Run the full 256-seed report using `tools/run_ablation_report.ps1` on Windows/PowerShell or `MidiForgeQA --ablation-report 256 ablation-report.csv` after building the headless QA executable. Results are diagnostic only: no production judge weights are removed or retuned.
